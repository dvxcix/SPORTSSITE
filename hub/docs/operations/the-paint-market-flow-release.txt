Changes
- Removed visible PRIVATE PREVIEW and BallDontLie labels. Server admin gates,
  noindex responses and exclusion from public navigation remain in force.
- Added a full sportsbook comparison with each book's own line/price/save action,
  FanDuel/DraftKings/Caesars ordering, and internally scrolling mobile tables.
- Research board and mobile cards include signed MM and +MM/-MM sorting.
  MM = sportsbook rank minus NBA performance rank within the same priced pool.
  Performance blends 60% season and 40% L10 observed production, minimum five
  appearances. Two-sided prices use normalized implied probability. Unknown
  samples remain unranked. This is a descriptive stat rank, not a trained model.
- Single-book quote selection now stays closest to the consensus line instead
  of accidentally picking the lowest alternate line.
- Posting rejects mixed books and duplicate player/market legs server-side,
  verifies exact fresh quotes and tipoff, and stores canonical name/team/date/line.
- NBA post and My Picks cards use NBA team logos rather than MLB artwork.
- Added NBA-only atomic service RPC: settle_nba_pick_exact(uuid,text).
  Applied individually as 20261019035712_nba_exact_atomic_settlement. No historical
  migration replay, flags, collector changes, existing data rewrite or job replay.
- Settlement locks parent then child, matches game/player/market/side/line,
  updates pick and post atomically, serializes parlay legs, and ignores retries.
  Mismatched post data raises and rolls back. MLB/NFL settlement paths unchanged.
- NBA final settlement now also runs on the existing two-minute grading schedule,
  concurrently with MLB processing, with the daily route retained as fallback.
  Future dates are excluded; bounded provider reads and a deadline limit work.
  No live-game losses, guesses from absent stats, or unknown/DNP losses.
