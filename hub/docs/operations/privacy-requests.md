# Privacy and account deletion

## Data exports

- Users request exports from account settings.
- Admins monitor queued, processing, ready, and failed requests from pipeline health.
- Export downloads require the requesting user’s authenticated session.
- Do not send exported archives through chat or support tickets.

## Account deletion

1. Review the user’s open request and identity.
2. Check active subscriptions, creator balances, payout obligations, disputes, and legal holds.
3. Block the request with a clear internal reason if money or compliance work remains.
4. Schedule deletion only after those checks pass.
5. Use the audited admin deletion action at the approved time.
6. Confirm authentication and application records are removed or anonymized according to policy.

The request queue is not itself permanent deletion. This separation prevents accidental removal while billing or creator obligations remain.
