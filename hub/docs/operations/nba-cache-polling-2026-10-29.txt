NBA shared cache polling — October 29, 2026

Slow slate refreshes can leave multiple application instances waiting for one
shared cache owner. Previously every poll downloaded the entire expired cache
payload, which can be multiple megabytes. Waiting readers now poll timestamps
and lease metadata only. When those indicate a fresh result, each reader fetches
and independently validates the complete row before using it. Initial reads,
freshness and stale policy, failure cooldown, source observation times, and
pregame/live boundaries remain unchanged. This does not remove owner writes or
initial payload reads and does not establish the database restart cause.

Validation: 23 focused shared cache/outage tests, including six simultaneous
independent followers and freshness/cooldown races; 102 pregame freeze tests;
134 production smoke checks; TypeScript and scoped lint. Independently reviewed.
No schema, capture, schedule, provider, or Browserbase changes are required.
Live deployment and natural traffic must be verified separately.

Follow-up: shared cache SELECT failures previously discarded their cause. A
private, rate-limited diagnostic now records only a fixed read operation and
allowlisted coarse failure category. It does not record cache keys, payloads,
error text, URLs, credentials or arbitrary database codes. Status-zero transport
failures remain ambiguous unless this request's own timeout signal fired;
database cancellation is not assumed to be a timeout. Thrown query exceptions
outside the returned error path remain unclassified. The public error and all
freshness, fallback and cooldown decisions remain unchanged. Diagnostic tests
cover redaction, rate limiting, deadlines, database errors and both read paths.

Slate finalization timing now also separates fixed, private closed-research,
frozen-rank and legacy-lookup buckets while retaining the overall finalize
stage. Buckets include adjacent synchronous work and are not query timings.
Repeated phase passes are accumulated, including failed finalization; no queries,
phase decisions, response contents or player identifiers are added or changed.
Focused diagnostics 8/8, freeze 102/102, production 134/134, TypeScript and
scoped lint passed; route lint retains three pre-existing warnings. Independently
reviewed. These timings support investigation, not a latency or restart fix.
