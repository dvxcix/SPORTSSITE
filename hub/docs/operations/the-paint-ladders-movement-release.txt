ThePaint ladders, market history and interface polish

Scope
- Kept page, data and post access admin-only and out of public navigation.
- Added first-class Ladders and Movement board tools and matching player tabs.
- Milestone and alternate O/U grids cover every supported NBA market, including
  points, rebounds, assists, threes and combined props. Each target shows its own
  live book price, exact saved-pick action and L20 descriptive hit rate. Best
  prices are highlighted only within the SAME target/side/type.
- Dedicated ladder player/book selectors replace redundant board filters; player
  selection persists when moving between stat markets. Panel tools expose side
  and market selection. Existing watchlist/post/grading identity paths are reused.
- Odds-cell clicks open ladders directly; +/-MM tools open the ranked research
  view and expose selected state. Added a prominent over/under control.
- Improved table hover/frozen columns, internal horizontal scrolling, mobile
  widths/touch targets, tool rails, panel spacing and drawer transitions. Reduced
  motion remains respected; charts represent observed data without smoothing it.

Actual market movement

  or writes. No historical migration tree was replayed.
- New cloud collector /api/cron/nba-market-capture runs every five minutes with
  existing cron authentication/health telemetry; no laptop collector or secret
  changes. It considers today/tomorrow, deduplicates schedules, checks pretipoff,
  caps 16 games/four parallel reads, and reports failed/deferred captures honestly.
- Economic fingerprints ignore provider IDs/order/timestamp-only changes. Actual

  is freshly admin-gated and returns baseline + latest 95 filtered captures.
- Reference-line movement is separate from fixed-threshold price movement.
  Book/market/player are exact; a line comparison never substitutes another book.
  Over/under price movement compares the same CURRENT threshold and side using
  implied probability points. Missing current quotes remain unknown.
- Reference lines are selected near consensus; they are not asserted to be a
  provider-designated main line. First shown is not a guaranteed sportsbook opener.
