NBA SCORE AND MODELS
nba-opportunity-v2 is a descriptive 0–100 research index, not a win probability:
35% opportunity, 20% minutes, 20% recent form, 10% role stability, 10% positional
allowance, 5% game pace. Points use FGA + .44 FTA; threes use 3PA; other count
markets use per-36 output. Quarters use quarter observations and 12-minute role
scaling; binary events use observed event frequencies. Five known observations
and 55% feature coverage are required; samples shrink to neutral until twenty
appearances. Missing components remain visible. Slate Edge uses the same DvP
and pace context as the score workspace and archived research.

DvP covers all thirty teams with each defense's own latest twenty games. It uses
opponent production per 48 position-minutes, first-listed G/F/C role, five known
games minimum and n/(n+20) shrinkage to the league position baseline. Early-season
fallback is labeled. This is positional allowance, not an asserted individual
defensive assignment. Full-game and quarter observation counts are separated.

nba-rolling-v1 forecasts are separately validated for all sixteen markets.
Candidate L10 and L5/prior-15 blends are chosen on 2023–24 and 2024–25, then
measured on held-out 2025–26 observations. Each prediction uses earlier verified
appearances only. Count markets select by MAE; binary events select by Brier
error. The UI reports actual training dates, source coverage and holdout size.
Examples: points MAE 4.667740 vs L10 4.716033; rebounds 1.922723 vs 1.949343;
double-double Brier .055149 vs .057672; triple-double .004577 vs .004816.
First-quarter MAE: points 2.210942, rebounds .923680, assists .699955.
These modest error changes do not establish betting profit, calibrated event
probabilities or an odds backtest. No historical sportsbook quotes were invented.
New rookies, inadequate samples and pages before validation completion withhold
validated forecasts rather than leaking future results.

MM, MARKET STORIES AND PUBLIC CONTEXT
MM = sportsbook rank minus observed-production rank within the same priced pool.
Positive means observed production ranks ahead. The baseline combines 60% season
production and 40% L10, with five appearances minimum; quarter baselines use the
available quarter facts. Two-sided prices are normalized without vig; one-sided
milestone prices are labeled implied prices including vig. Slate MM uses the
whole slate and is withheld on incomplete required coverage.

Market Story distinguishes changing thresholds from changing prices at the same
threshold/book/side. Cross-market finds opposite moves for the same player and
book and compares actual category public counts where available. Public captures
must match exact teams/date and exact normalized roster names. Repeated sections
are not summed. Missing counts remain unavailable, not zero. Pikkit counts are
pick categories, not wager dollars or exact-line counts. A divergence is a
research hypothesis, never evidence of bookmaker intent or a guaranteed edge.
The three opening matchups have real repeat captures and interactive results.

SAVING, POSTING, GRADING
Exact alternate, main over/under, first-quarter and double-double saves were
verified in the live shared watchlist, including persistence after reload.
The posting path rejects stale/changed prices, wrong side/book/player/game,
started games and invalid parlay combinations. Save -> post API -> My Picks ->
settlement is covered by integration regressions without publishing public test
posts. Live database rollback fixtures verified atomic single/parlay grading,
idempotent retries, parent rollup and one result notification per transition.
Fair rotating claims keep unresolved old appearances from starving newer picks.

Final grading requires exact player/game/phase, final status and verified
appearance. A rounded zero-minute row with positive actions is an appearance;
all-zero/no-evidence or missing-minute rows remain pending. DNP is not guessed
as a loss or automatic void. Full-game grades continue if quarter data fails.
Temporary save fixtures were cleaned up; SQL post/notification fixtures rolled
back. No public test posts, wagers or payment changes were performed.

SCALING AND OPERATIONS
Shared DB caches and refresh leases coalesce independent serverless readers,
with a bounded ten-second process cache and in-flight deduplication. A concurrency
regression exercised eight requests from four independent instances with one
provider load. Board cache 60s / bounded stale 300s; game browsing 15s, while
posting/grading revalidate fresh status. Tracking uses stored facts and a shared
900s cache; player clicks do not hit the provider independently. Board payload
fell from 3,179,254 to 1,374,449 bytes by retaining only needed typed log fields.
Authenticated conditional refreshes hash the semantic board: unchanged samples
return an empty 304 response with the confirmed source time, preserving the
browser's existing rows. Quote/stat/coverage changes return the complete update.
This is architecture/concurrency evidence, not a 6,000-user load-test claim.

Cloud-only ingestion resumes guarded exact cursors, never restarts completed
imports, and refreshes rolling sources every fifteen minutes, rosters six-hourly
and teams daily. The minute dispatcher skips current rolling sources in roughly
100ms. Models skip unchanged validated reports. Quote/research snapshots run
every five minutes; exact economic fingerprints preserve real price changes and
A->B->A. Research stores latest-pretip features, source log IDs, score version,
quote and validated forecast for future final outcomes. No synthetic 2026 finals.

Collectors cover all three calendar dates intersecting the rolling 48-hour
window. Quote and research attempts rotate oldest-first, including unsuccessful
attempts, so missing data cannot permanently starve later games. Quote scans no
longer truncate to the first sixteen games. Cached attempt receipts do not
inflate newly inserted capture counts. Pikkit remembers successful unchanged
reads separately from append-only changed-count history to preserve its cadence
without repeatedly paying for unchanged cloud captures.

Pikkit checks every ten minutes and captures due games at most every thirty
minutes in the next 48 hours, oldest first. Cloud browser startup, per-game work,
diagnostics and cleanup are bounded. Unlisted events defer honestly. Busy shared
context defers; uncertain browser shutdown retains its safety lease. Existing
NFL/MLB default browser limits and owner-approved NFL timeout hierarchy remain.
One earlier Pikkit execution timed out; the later real 07:11 UTC run captured all
three games and finished successfully in 48.060s. Timeout/cleanup regressions
cover healthy, startup hang, game hang, release hang and unlisted scenarios.

All fourteen NBA fact/cache/ledger tables have RLS and no anonymous/member direct
read/write privileges. Every NBA research API checks a fresh server-side admin
role before provider or service work. Guest redirect and member-denial contracts
pass. NBA access remains unchanged until the owner approves public release.
