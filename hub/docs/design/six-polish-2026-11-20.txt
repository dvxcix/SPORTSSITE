SlipSurge UI polish: six approved improvements, 20 November 2026

Scope: member and admin interface work. Team logos, bounded player portraits,
team colour backgrounds, odds values, grading, access gates and archived pregame
research remain intact. No database migrations, feature flag changes, captures,
billing operations or changelog publications are part of this release.

1. Player drawer
The drawer now has a fixed header and action footer around one scrolling body.
This removes the flex shrink that clipped identity text. The desktop panel is
640px wide; phone uses the viewport width and a native research section picker.
The chart precedes the projection card and log. All six existing sections remain.

2. Mobile board
Player search remains on the board. Market, target, book, team, sort, saved and
sample controls move into one sheet with a result count and persistent state.
The existing desktop controls stay inline. Only the active table/card presentation
renders. The NFL header uses one native workspace picker on phones, with the
existing week, date, game and stat sample retained when switching tools.

3. Tables and charts
Current prices lead each quote; opening price and exact probability movement
share a secondary line. Accessible labels and capture identity remain. Rows use
tabular numbers, quieter heat cells and less padding. Detailed NBA game charts
have a reference line, explicit hit/miss/push legend and keyboard point navigation.
Shot charts distinguish filled makes and outlined misses. Missing tracking
observations still break the line. NFL charts retain their underlying data.

4. Research navigation
Core NBA tools stay immediately visible. Boards, Trends and Matchups disclose
the remaining tools; the active group opens automatically. Sidebar search still
reaches every destination. The icon rail retains individual destinations. The
web and native desktop shells share the group component. The full-slate Odds
Board is also available in the desktop navigation.

5. Secondary surfaces
Settings headers and forms use flatter surfaces and smaller headings. Phones
use a section picker. Admin headers, statistics and navigation lose decorative
frames and redundant visible descriptions. Changelog instructions are shorter;
phone entry actions sit below the full title. Generic sports entity panels and
NFL board/research/cheatsheet surfaces use the same calmer contrast and borders.

6. Responsiveness work
Heavy unselected NBA research tools and drawer panels load on demand. Price
formatters are reused and quote values memoized. Desktop tables and phone cards
no longer render simultaneously. Opaque shell surfaces no longer apply backdrop
blur. Private fixture-only metrics have no analytics destination or production
mount; they are gated by the existing private design review environment.

These are local fixture observations, not production RUM, official INP or complete
data readiness timings. Do not extrapolate them into a universal speed claim.
