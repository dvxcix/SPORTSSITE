Replaces the primary Whop payout redirect with SlipSurge balance cards,
currency selection, 30/90-day gross revenue, daily breakdown, payout search,
status filtering, cursor pagination and payout details. Missing provider
values remain unavailable; currencies are not converted or mixed. Revenue
is explicitly gross before fees/refunds and shows its record cap when used.
Studio settings routes connected creators to their own balance/verification
page. Existing external endpoint remains for backwards compatibility.

Supported Whop Elements handle withdrawal amounts, payout destinations,
bank linking, fee review and KYC/KYB inside a focused theme-aware dialog.
Read-only page loads never mint write tokens. Deliberate dialog opening
requests ten-minute tokens with explicit account-specific action scopes.
Withdrawal and identity scopes are separate; no platform-wide token is
exposed. Tokens live only in component memory and expire out of the form.

Server resolves the authenticated profile's account, checks exact account
identity and platform parent, enforces configured MFA, same-origin JSON
actions, strict request shape, test-account restrictions and rate limits.
Ledger and payout serializers allow-list display fields; KYC, bank details,
metadata and raw provider failures never reach the dashboard payload.
Unavailable sources fail independently. No application fee is added.
