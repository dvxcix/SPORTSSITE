Sideline player comparison — 24 November 2026

Problem and resulting behavior
The old FTD% / ATD% labels were relative profit-payout changes against a player's
historical FanDuel average, not touchdown probabilities. The comparison now labels
those values Payout vs avg, with the historical sample and average price beside
them. A separate Implied probability row converts the actual FanDuel quote.
For the reported Burks capture: +850 is 10.5% implied, +290 is 25.6% implied;
the separate payout changes remain -70.5% / -68.0%. These are sportsbook-implied
values, not model predictions. Main-board columns now say FTD vs avg / ATD vs avg.
No scoring formula, ranking, quote, historical average or pregame input changed.

Comparison redesign
- One full-width, aligned table replaces a four-slot card grid and independent
  horizontal scrollers. Player count determines minimum table width. Shared row
  labels and player headers stay visible while scrolling the table.
- Matchup: contextual SlipSurge Score, Volume, Geometry, Red zone, Breakaway,
  Evidence, RZ looks, both TD prices/probabilities/historical references, observed
  picks and the existing FTD/ATD implied-probability ratio.
- NFL Tracking: all twelve existing drawer metrics, including aDOT, separation,
  YACOE, RYOE/A and CPOE. Missing/withheld metrics remain unavailable.
- Sportsbooks: market selector and one aligned row per captured book. Primary
  contracts first; All lines exposes every captured alternate, with exact side,
  threshold, opening quote and same-contract movement. Opening-only observations
  never become current prices or probabilities in the summary.
- Sample selector updates the same board window used by player details. Names
  open the existing drawer. Remove and Clear preserve the four-player workflow.
  Team portraits, logos, compact availability, rookie ribbons and verified final
  totals remain visible in comparison identities. Selection buttons expose state.
