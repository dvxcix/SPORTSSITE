SlipSurge NFL visual release — 2026-11-20

Scope
The Sideline's eight board groups, six NFL workspaces, three player drawer
sections, five Cheatsheets, eight Matchup Lab categories, four Sideline Edge
sections, Props controls, touchdown tracker, Matrix library/community/editor,
column manager, comparisons, game lines/capture replay, NFL player/team pages.
The visual inventory now contains 44 NFL items and 232 items overall.

Changes
- Consistent neutral surfaces, control sizes, typography, borders and spacing.
- Phone section selectors retain every tab; desktop rails retain keyboard access.
- Player drawers contain portraits inside team-color backgrounds, keep every
  sample and quote available, and use three/two-column metric layouts.
- Missing window/metric observations remain unavailable. Empty Last 1 no longer
  silently displays season production. Captured markets remain available.
- Original pick icons, known/estimated/missing counts and signed market icons.
  Movement requires comparable prices on the same observed line and side.
- Sportsbook comparisons retain distinct thresholds/sides, mark tied best prices
  and avoid calling a single sportsbook a best-price comparison.
- Saved portrait fallbacks survive failed images and theme rerenders.
- Sideline Edge can retry failures and retain its previous loaded slate.
- Live full-slate requests hit the ordinary 20-second polling deadline. Only
  this larger request now has a bounded 60-second allowance; ordinary polls stay
  at 20 seconds. Timeout copy explains recovery without raw browser errors.
  Collector extraction, dispatch and job timeout settings are unchanged.
- Team-page roster counts no longer imply every listed status is active, and
  the division label no longer repeats its conference.
- Table identity columns, long names, phone controls and overlay scrolling checked.
- A 320px toolbar regression was corrected with a two-column control layout;
  off-canvas overflow is contained by the NFL shell. The board guide opens as
  a readable popover without widening the phone page.
- Existing NFL data methods, entitlement, freezes, collectors and feature flags
  are unchanged. No database mutations, jobs, picks, publishing or matrix writes.
- Live review caught an existing Defense / DvP filter defect: Both Teams included
  unrelated league defenses. It now displays only the selected matchup, preserving
  the complete comparison pool and each team's sample. A regression test covers
  both teams, one team and return navigation without mutating the source lens.
