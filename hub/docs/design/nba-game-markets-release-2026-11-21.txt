SlipSurge NBA game markets and public activity — 2026-11-21

What changed
The selected NBA game's moneyline, spread and over/under now sit above the
research workspace in three market cards. Phones use a native horizontal
carousel with arrow and keyboard controls. The book selector changes real
prices. Teams retains the original pace/ratings and confirmed-starter links.
The header also appears on Odds Board, which reads only the selected game's
existing phase-safe game-price archive rather than a heavy player board.
A missing player-research snapshot cannot remove the selected game markets;
the independent header remains available while player research stays unavailable.

The existing pikkit_pregame_overviews archive is now exposed through a gated,
read-only NBA endpoint. It supplies the observed game pick total, wager total,
pick shares and wager shares. Each snapshot shows its own ET capture time.
These aggregates are separate cohorts from sportsbook prices. No side pick
counts are derived from the all-market total, and the source's Full/1st Half/
1st Quarter groups are never presented as bookmakers. No collector, schedule,
budget, job replay, schema, secret or feature flag was changed.

ThePublic now uses the existing original crowd mark beside counts, a desktop
table and dedicated phone cards. Player/market filters, every sort direction,
capture provenance, zero counts, carried deltas and analysis links are retained.
The component remounts on a research snapshot or odds-mode boundary so previous
public data cannot carry into a different research scope.

Odds Board phone overflow was traced to absolute screen-reader labels whose
containing block was the page shell. Its table scrollport now establishes the
containing block. Before: document width 3267px at a 390px viewport. After:
document width 380px, with all 3324px of table columns still independently
scrollable. The same containment applies to NBA research table scrollports and
the market carousel. No tools or columns were removed to solve this defect.
Availability uses the same honest Lineup not confirmed wording as Teams.
