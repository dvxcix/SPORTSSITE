Member workspace defaults — 2026-11-21

This release completes the Court heat-color regression and adds private, durable
sportsbook and launch-page preferences. It does not certify the remaining site.

Member experience
- Settings > Your workspace: choose preferred books, a primary book and a launch
  page. Settings navigation works in the desktop sidebar and phone section menu.
- Root/Home and default password, OAuth, Whop and desktop OAuth completion use
  the saved launch page. Installed web-app start_url uses /launch; its id stays /.
- Direct destinations retain precedence. New-account onboarding remains mandatory.
  Saved NBA/NFL launch choices recheck current access and fall back to Feed after
  revocation. No arbitrary stored redirect URLs or stale game/date are accepted.
- NBA single-book research, Odds Board and game header use the primary default.
  NBA price comparisons/first-basket comparisons, NFL sportsbook comparisons,
  expanded vendor columns and game lines start with the saved book set. NFL
  Props and Odds Board start with the primary book. Every available book remains
  reachable. If no preferred comparison book is present, captured books appear.
- NBA comparison links preserve the visible book set through URL normalization;
  manual All books overrides remain in the shared URL. Existing fixed analytical
  references, pregame boundaries, archives, models and entitlement policies remain.
- Court L5/L10/L20 continuous red/green fills and borders are restored. Sample
  counts, neutral missing values and contrasted text remain visible.
