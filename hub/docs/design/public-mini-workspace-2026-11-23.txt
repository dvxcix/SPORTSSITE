Integration receipt, not a production publication claim.

Owner direction
The homepage must show SlipSurge's real product identity and interactions:
player portraits, team backgrounds/logos, league marks, sportsbook logos,
priced rows, proper controls and a player detail view. A text-only odds table
and brochure split are insufficient. The working mini workspace leads the page.
Research models, score formulas and private member data stay outside this UI.

Implementation
- LandingPage now accepts previews?:Record<PreviewSport,ResearchPreview> and
  showcase?:ReactNode. The centered short intro precedes a full-width workbench.
  The parent can stream its async current-board component under Suspense.
- ResearchShowcase consumes actual server props. No featured player IDs,
  November 8 dates, individual final results or prices are hardcoded in it.
  Omitted props use the existing explicitly dated public archive for tests.
- The frame is a condensed SlipSurge workspace: league/workspace navigation,
  actual game/team strip, market/book toolbar, Players/Ladders views, milestone
  controls, priced rows, selected-player inspector and player detail drawer.
- Six visible players at most; rows quoted at the selected rung sort before
  missing quotes. Player and ladder tables have contained scroll regions.
- Player clicks open the shared ModalSurface. The drawer has Overview and All
  odds views, a real observed/market chart and an exact full-preview handoff.
- Market/book/more-tools controls explain the free scope in a dismissible
  dialog. Membership links retain approved research context. Save shows the
  account action instead of pretending that a pick has been saved.
- No initial account requirement is added. The user can continue free browsing.
- Current/fallback labels come from board.example. Game dates, saved time,
  scores and quote values come only from the supplied board.

Chart honesty
- Recent bars exist only when actual recent values are supplied. Observed zero
  remains zero. The ordering is oldest to newest, labelled by observation index
  because this bounded shape does not include dates. No dates are invented.
- Without recent data, the chart shows only actual offered ladder quotes.
  The same public American-odds helper used by the existing market UI supplies
  their visual height. No research model or player score is calculated here.
- Bars animate their entrance only; no random values, timer, fabricated updates
  or synthetic results. Selection is explicit and prices remain unchanged.
- Existing supporting player artwork/story remains separate and dated.

Design/gate receipt
Reading this as a public sports research workspace with SlipSurge's existing
team/player identity. ENERGY 2 / RHYTHM 2 / MOTION 2.
Purpose: real artwork identifies the athlete/team/league; book marks identify
the quoted market; accent identifies selection. The frame demonstrates an
actual product task instead of decorative browser chrome or fake dashboards.
Motion: 160–240ms selection/drawer/bar entry, all reduced-motion guarded.
No unsupported statistics, testimonials, performance claims or private formulas.
Native buttons/links, named actions, shared ModalSurface focus/Escape behavior.
Source and component safety gates pass. Browser layout, contrast, font sizing,
theme, touch and final release gates remain with the coordinating root agent.

Phone legibility correction
After the coordinator flagged tiny metadata, primary phone odds/player names
were set to 13px, controls to 12px and supporting/chart labels to 11–12px. The
secondary Move column collapses on narrow phones; movement remains accessible
in player details. The two core columns preserve identity, current/open price
and source information without shrinking to 8–9px. As-of labels may wrap.
Root still owns actual visual verification across all themes and widths.

Test type correction

real component's parameter type. The PostCSS ancestor walk uses Node|undefined,
preserving the actual reduced-motion assertion while permitting Document nodes.
