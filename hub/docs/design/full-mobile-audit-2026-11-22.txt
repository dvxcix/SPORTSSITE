Changes in this release
- VOLT is the only floating launcher everywhere. My Picks and Watchlist remain in page headers and the account menu. Existing drawer hosts/listeners stay mounted, and MLB/NFL matrix access is retained in its workspace.
- Comments use multiline fields with separate emoji/GIF/send rows, caret-preserving insertion, pending feedback and Ctrl/Command+Enter submission. Enter adds a line. Duplicate comment/reply submissions are blocked; failures retain text. A pending reply cannot switch threads and discard a draft. Deleting a branch updates the count for every removed reply.
- Comment authors, badges, timestamps and actions now fit narrow phones. Deep threads cap indentation. Edit, delete, report and block stay in a compact, keyboard-accessible actions menu. Profile links remain available on avatars and names.
- Member hover cards have a contained avatar, readable identity/badge layout and a clear profile link. Unknown follower counts are omitted. Hover cards stay out of phone navigation; the member's profile link still works. Existing decoration, ring, badge and privacy behavior is preserved.
- Feed composers show a neutral loading state while authentication resolves, instead of flashing a false sign-in prompt. An unavailable account shows a retry state.
- Channel chat uses the full available writing width on desktop, phone and short landscape, with separate touch controls below the field on smaller screens. Its room height subtracts all visible navigation/banner chrome; Send stays reachable. Seven compiled width/clearance checks pass, including 320px and 844x390.
- DM and group-DM composers have a full-width writing row and separate media/send controls. Conversation height accounts for navigation and banners, keeping Send visible. VOLT and the resume prompt step aside while a text field is focused.
- Community navigation reveals the current section when it would be offscreen. Feed/activity/hashtag counts use the correct singular form.
- Admin Blogs, Stories, Events, Groups and Pages tables scroll instead of clipping columns, with named keyboard-focusable regions. Member rows are compact; Manage expands the original administrative controls. HR Intelligence's date and action no longer overlap. Creator administration has consistent outer spacing, and mobile breadcrumbs avoid wrapping group labels.
- NBA chart bars have 44px phone hit areas and horizontal scrolling, including automatic keyboard focus scrolling. Game-market slider controls, table sort headers, matrix actions, notification filters/dismiss controls, search/menu controls, comparison clearing and workspace actions have usable phone targets. Data, prices, scoring formulas and frozen pregame rules are preserved.
- Landing and public-preview theme controls sit in header flow, with no overlap on sign-in/account links. Preview controls and phone branding fit small screens.
- The GIF picker has larger phone category, retry and upload/link controls. Emoji controls and text fields fit without crowding the draft.
- Onboarding restores the saved draft before showing interactive steps, preventing a late restore from overwriting the first click. Denied browser storage still opens setup. The final review has a Back action, and photo upload has a full touch target.
