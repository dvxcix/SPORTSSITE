CHANGES
Prices lead each quote. Original SVG count marks replace repeated pick labels.
Estimated counts retain an approximation sign; missing values remain distinct
from zero. Signed chart marks retain probability-point and direction meaning in
accessible labels. One board guide explains the symbols. Opening/earlier prices,
stale coverage warnings, result grades and exact quote drill-downs remain intact.

Duplicate visible board headings were removed. Phone controls keep accessible
labels while reducing repeated text. Tablet controls respond to their available
panel width. The mobile Tools picker retains all 17 NBA and six NFL destinations.
Permanent The Court/Odds Board and The Sideline/Odds Board switches remain.

Avatar rings now have an isolated stacking context, with the photo above the
ring and presence above the photo. Photos are not tinted by a theme filter.
Wide Ultimate artwork retains its proportions. Light theme tier chips use paired
readable ink/background colours. Badge descriptions work by keyboard and tap.

A read-only live check found 1,227 badge assignments across 1,119 members.
The old unpaginated read was vulnerable to the documented default response cap:
https://supabase.com/docs/reference/javascript/v1/select
The new shared read walks the assignment primary key in pages of 500. A failed
page cannot publish an empty or partial badge list. Failed refreshes retain the
last good list, explicit invalidation refreshes mounted identities, and a reused
row looks up its current member immediately. Existing RLS and assignment rules
are unchanged. The live REST cap itself was not changed or independently queried.

The shared image component also handles failures that finish before hydration,
plus later native error events. New source URLs recover; theme changes preserve
the successfully loaded image node. A bad URL displays the existing fallback.
It does not fabricate artwork or retry invalid uploads indefinitely.
